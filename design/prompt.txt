请为我生成一个完整的、单文件可运行的 HTML 塔罗占卜系统设计原型。

# 项目背景
这是一个"娱乐向 + 注重设计效果"的塔罗牌模拟系统。用户输入问题 → 洗牌抽牌 → 获得结果解读。设计目标是：仪式感强、视觉高级、有完整的组件设计语言（可作为设计系统沉淀）。

# 核心功能流程
1. **提问页（首页）**：深邃星空背景，居中一个"请输入你的问题"输入框 + "开始占卜"按钮。下方提供 2 种牌阵选择：单张牌（今日指引）和三张牌阵（过去·现在·未来）。
2. **抽牌页**：洗牌动画 → 牌面朝下在桌面上扇形展开 → 用户依次点击选牌（或"自动选牌"）→ 牌 3D 翻转揭示，显示正位/逆位。
3. **解读页**：完整展示抽到的牌（牌名、罗马数字编号、正/逆位标识、位置含义），下方是一段结构化综合解读——一个标题 + 3~4 个小要点 + 一段总结建议，口吻像一个沉静的"灵性顾问"（占位文案，精心撰写）。
4. 页面角落提供"重新占卜"入口。

# 视觉设计语言（重点，请严格执行）
- **主题**：神秘塔罗 / 午夜天文台。深空感 + 星象元素（星轨、星座连线、新月、光尘粒子）。
- **配色**：主色 深夜蓝紫（#1a1033 / #231a4d），强调色 月光金（#d4af37 / #e8c97a），辅助 星芒白（#f4eef8），逆位警示色 暗锈红（#8a3b3b）。背景 2~3 层渐变 + 星点纹理。
- **字体**：标题用衬线展示体（Playfair Display / Cormorant / 'Noto Serif SC'），正文用纤细无衬线（Inter / 'Noto Sans SC'），中西文兼顾。
- **质感**：卡牌有金线描边、轻微 3D 压感、hover 时微光浮动；牌背是纹章式花纹（用 CSS/SVG 绘制，禁止外链图片）。
- **动效**：洗牌横向抖动、翻牌 rotateY 3D 翻转、揭示时辉光扩散、解读文字逐段淡入。节奏舒缓（0.6–1.2s），忌生硬。
- **布局**：居中纵向流，留白充足，低信息密度，视线引导 问题 → 牌 → 解读。

# 技术约束
- 单个 HTML 文件，内联 CSS 与原生 JS（无框架、无构建、无外链依赖；字体可用 Google Fonts CDN）。
- 用 JS 数组内嵌 22 张大阿卡纳（中文名 + 罗马数字编号）。
- 抽牌用随机算法；正位/逆位各 50%，逆位牌名下方加小三角标识。
- 这是设计原型而非生产代码：解读用精心撰写的占位文案，但 UI 结构、间距、动效必须像素级完整。

# 设计系统沉淀
在 :root 中定义全套设计 token：--color-* 色板、--font-*、--space-* 间距阶梯、--radius-*、--shadow-*、--dur-* 动效时长。组件类名清晰（.card / .btn / .input / .spread / .reading 等），方便后续在此基础上沉淀设计系统。
